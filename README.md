# World Bank Population Distribution Visualization

## Task Description

Create a bar chart or histogram to visualize the distribution of a categorical or continuous variable.

## Dataset

Dataset source: World Bank indicator `SP.POP.TOTL`

Indicator name: Population, total

Dataset link:

```text
https://data.worldbank.org/indicator/SP.POP.TOTL
```

## Visualizations

This project creates:

- A bar chart showing the top 10 countries by population
- A histogram showing the distribution of country populations

## Technologies Used

- Python
- Pandas
- Matplotlib

## How to Run

Install required libraries:

```bash
pip install pandas matplotlib
```

Run the script:

```bash
python visualize_distribution.py
```

## Output Files

```text
top_10_population_bar_chart.png
population_histogram.png
```
